# Security Policy

## Supported Versions

Only the latest published version of this repository is maintained.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |

## Reporting a Vulnerability

If you find a security issue in this repository, please **do not open a public issue**.

Use GitHub's private reporting instead:

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Describe the issue with reproduction steps

You can expect an acknowledgement within 48 hours and a status update within 7 days.

## Scope

This repository holds a GitHub profile README and community health files. Reports about
third-party badge services (for example `github-readme-stats`, `readme-typing-svg`,
`github-readme-streak-stats`) are **out of scope**, since they are external services and
this repository only links to them.
